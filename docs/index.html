WHAT IT DOESCompose, arrange, sound design, sampling, drums, mix, master, listen.

AI music production inside Ableton Live

Ableton Studio MCP is a Model Context Protocol (MCP) server and an Ableton Remote Script. Together they connect Ableton Live to Claude Code, Claude Desktop, Cursor and other MCP clients. The assistant can assist you, or take over: it writes MIDI, builds patches like a synth programmer, listens to the result like a mastering engineer and reasons about harmony with real music-theory knowledge.

Features

1.

Make tracks with

DRUMS AND GROOVE

19 electronic drum patterns or your own step grids: Euclidean and polyrhythmic layers, ratchets, ghost notes, probability, fills, swing, Groove Pool.

Program 8 bars of rolling techno on the 909 kit, with a 5-in-16 percussion layer.
MUSIC THEORY

About 50 scales and modes, 24 style sheets from baroque to techno, key and chord analysis with roman numerals, voice-led progressions, 18 clip transformations, Live 12's song scale.

Give me a deep house progression in A minor with offbeat stabs.
ARRANGEMENT

Curves over 16 to 64 bars on extended clips, and whole Arrangements built from Session clips by section (DJ-friendly techno, minimal, house), with locators.

Lay out a 64-bar techno arrangement with a DJ intro and outro.
STRUCTURED HUMANIZATION

Quasi-periodic rhythms and irrational rotations: variation that never repeats but stays even, instead of random noise. Always your choice, never applied by default.

Give the hats a quasi-periodic groove, on the rotation I pick.
2.

Shape sounds with

SOUND DESIGN

Build classic sounds (sub, acid, reese, pluck, pad, supersaw, FM bell), set every parameter with musical values, play a test phrase, measure it, tune it, and save it to your User Library.

Build a reese bass, play it to check the low end, and save it.
SAMPLING

Load and slice samples in Simpler; chop a loop in one call, warped to the tempo and transposed to the song's key, as a hook, a rearrangement or a stutter.

Chop this guitar loop into a hook in the song's key.
PRESETS AND PLUG-INS

Search and read the presets of Live's devices, racks and packs; VST, VST3, AU and Max for Live devices load like built-in ones.

Find me a dark plucky preset in my packs and tell me what it does.
3.

Finish with

LISTENING

Records the main output and looks at it: tonal balance against a reference curve, resonances, stereo width per band, low-end mono, each track's level and a spectrogram image.

The low end is muddy. Find out why and fix it.
MIXING

Volume, pan, sends, routing, return and main-track effects, Compressor sidechain, every parameter read as Live displays it.

Duck the bass with the kick.
MASTERING CHECKS

Loudness per EBU R128 (integrated, short-term, range), true peak and PLR, with ranked fixes for streaming, club, broadcast or podcast targets.

Listen to the whole track and tell me if it's ready for streaming.

Quickstart

You need Ableton Live 11 or 12, uv and an MCP client. Python and the dependencies are installed by uv.

  1. Add the server to your MCP client. In Claude Code: 
    claude mcp add ableton -s user -- uvx ableton-studio-mcp
    In Claude Desktop or Cursor, use the command uvx ableton-studio-mcp.
  2. Install the Remote Script into Live: 
    uvx ableton-studio-mcp install
  3. Enable it: restart Live, then Settings, Link, Tempo & MIDI, Control Surface: AbletonStudioMCP (Input and Output: None).
  4. Check: 
    uvx ableton-studio-mcp doctor

Full instructions, updating and troubleshooting: README on GitHub.

FAQ

How do I control Ableton Live with Claude?

Add the server to Claude Code, Claude Desktop or Cursor, install the Remote Script into Live, select AbletonStudioMCP as a control surface, then ask in plain language.

Can an AI mix and master in Ableton Live?

It can measure and act: it records the main output and reports integrated loudness (LUFS), true peak, loudness range, tonal balance, resonances and stereo width against a target, then adjusts the mixer, EQ Eight, Compressor and Limiter.

Does it work with Live 11, Live 12, Max for Live and plug-ins?

Live 11 and 12 (Live 12 for the song scale). Max for Live devices and VST/AU plug-ins load like built-in devices; Push keeps working alongside it.

Does it run on macOS and Windows?

It is developed and tested end to end on macOS. The installer and the preset search also handle Windows paths; Windows has not been tested end to end yet, so reports are welcome in the issues.

Does it collect any data?

No telemetry, no analytics, no account. The server only talks to Live on your own computer and makes no internet connection.

Which MCP clients are supported?

Any client that speaks the Model Context Protocol: Claude Code, Claude Desktop, Cursor and others.
